# Social Previews

Dashboard Previews links to `/preview/social/` in the isolated sample build (the live dashboard uses `/hub/preview/social/`). This read-only tool fetches actual public HTML in the viewer's browser, with cookies and referrers omitted, no server proxy and no publishing controls. It rejects non-HTTPS, URL credentials, custom ports, literal IPs and local hostnames. It does not bypass CORS, redirects or access controls. Direct URLs are required; errors clear the prior result. Reads time out after 15 seconds and stop after 2 MB.

The card is explicitly reconstructed, with Open Graph → Twitter → HTML fallback. Raw observed fields, canonical, robots and check time remain visible; missing fields stay missing. Remote HTML is parsed in an inert document and only text values are rendered. No remote scripts or markup execute. Supported share images load with no referrer, reporting natural dimensions or actual failure; browser load is not proof of crawler access, cache freshness or platform rendering. Client-injected head tags, actual Facebook/LinkedIn/X scrape results and live OAuth are not tested. Cross-origin sites without CORS cannot be inspected by this static tool and show an honest failure rather than cached or invented data.

QA covers actual exported home metadata/image, controlled successful/missing/malformed/blocked responses, image failure, credential-free fetch policy, hostile text safety, narrow/tablet/desktop layouts, both themes, keyboard and axe. Controlled fixtures prove error behavior, not a real social-platform scrape. No content or metadata on inspected pages is changed.
