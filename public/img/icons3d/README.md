# 3D icons

Airbnb-style 3D icons from Microsoft's Fluent Emoji (the "3D" style), MIT licensed (see LICENSE.txt).
Source: https://github.com/microsoft/fluentui-emoji/tree/main/assets — `<Name>/3D/<name>_3d.png` (some under `Default/3D/`).
Retrieved 4 Nov 2026, resized to 128×128 PNG. Use through `components/ui/Icon3D.tsx`, which maps meanings to files
(`lib/icons3d.ts`). They are illustrations, not brand marks: no official logos are drawn here.
